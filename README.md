# -AI-
针对个性化备考系统融合认知科学与大模型、缺失教师全景监控的问题，本文提出融合艾宾浩斯遗忘曲线与 SM‑2 算法的双引擎复习调度框架，集成大模型实现概念解析、薄弱点诊断、备考规划等 AI 分析能力。系统采用 uni‑app、Vue3+ECharts、Spring Boot 三层架构，实现师生角色鉴权。构建协同复习调度与加权薄弱点分析算法，驱动复习任务与学习优先级量化输出。考研场景实测表明，复习决策自动化率 100%，教师端可识别不同风险等级学生，数据刷新延迟低于 500 ms，科目自动分类准确率达 100%。该 “学生‑AI‑教师” 三位一体模式为智能教育提供可复制的算法工程范式，后续将研究消息推送与强化学习路径规划。
